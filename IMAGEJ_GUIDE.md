## ImageJ: manual reproduction

Detailed Chinese instructions: `IMAGEJ_MANUAL_CN.md`. In the current Notebook use 1 Select region, 2 Trace shaft, 3 Analyze, then run the final Save result cell. Keep the Shaft reference fixed when adjusting the Spine fluorescence threshold.

1. Open the CZI with `Plugins > Bio-Formats > Bio-Formats Importer`. Match scene, channel and time; check X/Y pixel sizes and unit in `Image > Properties...`. Keep the original bit depth. For max projection, use `Image > Stacks > Z Project...` with the same layers; Fiji layers are usually numbered from 1. Duplicate the projection for analysis. [Bio-Formats](https://bio-formats.readthedocs.io/en/stable/users/imagej/load-images.html)
2. Use Segmented Line to trace one shaft near the first dendritic branch above the soma, proximal to distal. Start after the branch swelling at the chosen offset. With `Analyze > Set Measurements...`, disable Limit to threshold and set Decimal places to 4; `Analyze > Measure` gives L. Adjust the distal vertex until L matches the target within a declared tolerance, e.g. one pixel size, and keep the measured L as denominator. Do not Fit Spline. Add the line to `Analyze > Tools > ROI Manager...` with T; rename it `Centerline` and save the ROI. A manually drawn line is not guaranteed to have exactly the program's arc length. [Line tools](https://imagej.net/ij/docs/tools)
3. On a duplicate, set the line width to cover both sides, then `Edit > Selection > Straighten...` for horizontal inspection. Save this view separately. Return to the source image for area measurement; straightening resamples pixels and can fit a spline. [Selections](https://imagej.net/ij/docs/guide/146-27.html)
4. On the source, use Polygon/Freehand Selection to outline a corridor of the chosen half-width, with both ends perpendicular to the local centerline. Add it as `Corridor`. Set `Process > Binary > Options...` to Black background, then `Edit > Selection > Create Mask` to obtain a full-size corridor mask. Save it.
5. On a source duplicate, use `Image > Adjust > Threshold... > Set` with the same lower limit and the maximum stored intensity. Convert using `Process > Binary > Convert to Mask`; white must be 255 and black 0. AND this mask with the corridor using `Process > Image Calculator...`, Create new window. Initially set Gaussian/background correction to 0 in the program; its rectangular-opening correction differs from Fiji rolling ball.
6. On the source, independently outline the shaft edges with Polygon/Freehand Selection; add/save a `Shaft` ROI and Create Mask. Clear unwanted branches, crossing fibers and detached signal from the positive mask: select each unwanted region, set background color to black and `Edit > Clear`. Retain only signal attached to this shaft; inspect dim necks in the original Z planes.
7. Keep a copy of the cleaned positive mask. Shaft-positive mask = positive AND shaft-domain mask. Candidate mask = positive AND an inverted copy of the shaft-domain mask (`Edit > Invert`, then Image Calculator AND). Never use Invert LUT for numeric inversion. Keep all masks the same size as the source. [Binary masks and image operations](https://imagej.net/ij/docs/guide/146-29.html)
8. In `Analyze > Analyze Particles...`, enter the matching area range in calibrated units, Circularity 0-1, Show Masks and Include Holes unchecked. Inspect the result against the candidate mask; do not fill holes. Reject the entire protrusion component when it exceeds the reach limit from the shaft edge, using a line measurement to check reach. Connected components are not spine counts. Keep the final white-pixel mask as `Spines`.
9. On Spines, `Edit > Selection > Select None`, set threshold 255-255, and `Analyze > Set Measurements...`: Area, Limit to threshold, Redirect=None. Measure A, then compute A/L (um2/um). On the source, restore the Centerline ROI and disable Limit to threshold when rechecking L. Save results as CSV and all masks as TIFF. [Measurements](https://imagej.net/ij/docs/guide/146-30.html)
10. To mark the original image, threshold the shaft-positive mask 255-255, use `Edit > Selection > Create Selection`, then T to add its composite ROI. Repeat for Spines. Rename the two ROIs `Shaft` and `Spines`; select each in ROI Manager > Properties and set green and magenta stroke colors. Activate the full-size source, select those two ROIs and Show All (or `Image > Overlay > From ROI Manager` in a manager containing only these ROIs). Save the ROI set with More > Save. Save the source with overlay as TIFF; use `Image > Overlay > Flatten`, then `File > Save As > PNG...` for a permanently marked copy. Keep the raw CZI/projection unchanged. [Overlays](https://imagej.net/ij/docs/guide/146-28.html)

To check exported values with menus: open `source_raw.tif`, import `centerline_xy.txt` via `File > Import > XY Coordinates...`, then `Edit > Selection > Area to Line` to obtain an open polyline. Measure L without Fit Spline. Open `source_spine_mask.tif` and repeat step 9 for A. Imported coordinates preserve the selected path subject to ImageJ coordinate precision. These files use full-source coordinates; do not import them onto a cropped image. [Coordinate import](https://imagej.net/ij/docs/guide/146-26.html)

Run the final Save result code cell after valid selections/parameter edits to write output. `source_annotated.png` and calibrated RGB `source_annotated.tif` preserve the full real projection size and original orientation: yellow=selected region, green=shaft contours, magenta=candidate contours/boxes, cyan=centerline. `source_labels.tif`: 0=unlabeled, 1=shaft, 2=spines. Only the chosen segment is classified. Candidate boxes are not spine counts. Compare masks spatially; matching A/L alone does not validate segmentation.
